# Firework for Music Web

[打开实时体验](https://fishxin.github.io/Firework-for-Music-Web/)

iPhone 优先的音乐互动烟花体验。点击开始，再点烟花画面结束；可切换三种模式或导入本地音乐。

此仓库只保存可运行的单文件页面和站点配置，不包含开发工程、测试与制作脚本。网页运行所需的脚本和音频会发送到浏览器，不能视为保密内容。

部署：GitHub Pages，从 `main` 分支根目录发布，启用 HTTPS。

本地音乐由浏览器处理，不上传。本项目为交互原型，不连接实际按摩设备。未授予开源许可。

支持音乐版、FJL-白噪音版、MZC-白噪音版，可在右上角切换；支持手机、横屏、平板及电脑全屏自适应。

右上角玻璃菜单统一提供三类版本及“上传我的音频”；模式区省略号入口已移除。本地音频只在浏览器内读取，不上传服务器。站点及主屏幕图标已补齐，开始与菜单图标使用内嵌 SVG。
